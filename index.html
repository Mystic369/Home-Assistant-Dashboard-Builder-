💡 Requirements:
• Add cors_allowed_origins to your HA http: config
• Use your external URL (no port for Cloudflare)
• Create a Long-Lived Access Token in your HA Profile
No :8123 needed if using Cloudflare tunnel!
Create in HA → Your Profile → Long-Lived Access Tokens → Create Token

Frequently Asked Questions

How do I import my existing dashboard?

Click "Import" → "YAML" tab, paste your dashboard YAML, and click Import!

Can I use this offline?

Yes! This tool works 100% in your browser with no internet connection required.

Where is my data stored?

Everything is stored in your browser's localStorage. Check Performance Monitor for usage details.

How do I connect to my Home Assistant?

Click "Connect HA", enter your HA URL and long-lived access token. Your entities will be imported!

What's the difference between YAML and UI mode export?

YAML export gives you code to paste in HA. UI mode is for using within HA's visual editor.

Can I share my dashboards?

Yes! Use GitHub Gist export, QR code generator, or the community sharing features.
